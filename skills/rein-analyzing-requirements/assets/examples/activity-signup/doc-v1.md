# 活动报名 PRD

版本：V1.0-1112　　产品：小周

## 1 背景

景区经常办线下活动，比如讲解、亲子手作、夜游。现在小程序上只能看活动介绍，游客要打电话报名，工作人员手工记名单，经常记错、超员。这期让游客直接在小程序上报名。

## 2 B 端：活动管理

### 2.1 设置报名

- 新建、编辑活动时，可以打开「需要报名」。
- 打开后要填名额和报名截止时间。名额填 1～9999 的整数。
- 报名截止时间必须早于活动开始时间。

### 2.2 报名名单

- 活动列表每一行加一个「报名名单」入口。
- 名单显示姓名、手机号、报名时间、状态，按报名时间倒序，每页 20 条。

### 2.3 导出报名名单

- 名单页右上角加「导出」按钮，导出当前活动的全部报名，格式是 Excel。

## 3 C 端：游客报名

### 3.1 活动详情页

- 需要报名的活动，详情页显示剩余名额和报名截止时间。

### 3.2 报名

- 点「立即报名」，填姓名和手机号后提交，报名成功。姓名、手机号默认带出上次填的。
- 每个人同一活动只能报一次。
- 名额满了或过了报名截止时间，按钮置灰，分别显示「名额已满」「报名已截止」。

### 3.3 我的报名

- 「我的」页面新增「我的报名」，按活动开始时间倒序列出报过的活动。

### 3.4 取消报名

- 活动开始前 24 小时内不能取消。
- 取消后名额放回。

### 3.5 报名提醒

- 报名成功后发一条提醒。
- 活动开始前一天再提醒一次。

## 4 上线安排

- 线上先关着报名入口，运营在测试环境确认没问题后再打开。

## 5 这期不做

- 付费报名。
- 报名表自定义字段。
