# Personal Skills Collection

这是一个用于沉淀、收藏、整理个人常用 AI/Agent skills 的仓库，方便后续复用、维护和持续扩展。

## 项目简介

这个仓库主要用来集中管理不同场景下可复用的 skills 配置与辅助资料。当前内容以个人使用和长期积累为主，重点是把常用能力按目录归档，减少重复编写，方便后续快速查找和复用。

## 仓库用途

- 收集个人日常会反复使用的 skills
- 沉淀固定规则、输出格式和模板约束
- 为不同任务场景准备可复用的参考资料
- 逐步整理成便于维护和扩展的个人技能库

## 当前收录

- `api-doc-standardizer`
  用于将自然语言形式的 API 描述整理为结构化的 Markdown 文档，适合接口文档补全、接口变更说明整理等场景。

## 目录结构

仓库按 skill 目录组织。每个 skill 通常包含以下内容：

- `SKILL.md`：skill 的主说明文件，定义用途、规则和输出方式
- `references/`：可选的参考资料目录，用于存放模板、示例或补充说明

当前结构示例：

```text
skills/
├─ api-doc-standardizer/
│  ├─ SKILL.md
│  └─ references/
│     └─ templates.md
└─ README.md
```

## 使用方式

使用这个仓库时，可以先根据任务类型找到对应的 skill 目录，再阅读其中的 `SKILL.md` 了解它的适用场景、规则和输出要求。如果某个 skill 附带 `references/`，通常可以继续参考其中的模板或示例内容来辅助使用。

这个 README 只负责介绍仓库本身。每个 skill 的具体细节、边界和模板规范，仍以各自目录中的说明文件为准。

## 维护说明

这个仓库以个人长期积累为目标，重点保持以下原则：

- 简单清晰，便于后续快速回看
- 结构稳定，方便持续扩充新的 skills
- 内容可复用，尽量减少临时性和一次性描述
- 资料归档完整，便于后续调整和迭代

后续如果继续扩展，这个仓库会逐步覆盖更多文档生成、规范约束、模板沉淀和自动化辅助相关的 skills。
